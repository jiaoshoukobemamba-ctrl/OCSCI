# 🧪 海洋化学：过程分析中心

海洋通过复杂的化学过程调节地球环境。

[cite_start]::: info 核心课题：海洋碳泵 [cite: 6]
海洋利用四个关键泵过程调节大气中的 CO₂：
1. **溶解泵**：物理溶解与温盐环流转运。
2. **生物泵**：浮游植物固碳并下沉。
3. **碳酸盐泵**：CaCO₃ 壳体沉降。
4. **微生物碳泵 (MCP)**：封存惰性溶解有机碳。
:::

## [cite_start]1. 海水化学平衡与酸化 [cite: 3]
在开阔大洋中，海水组分遵循**恒比定律**，但在河口或冰冻区会发生偏离。


### 化学平衡方程式
当 CO₂ 溶解于海水时：
1. `CO₂ + H₂O ⇌ H₂CO₃`
2. `H₂CO₃ ⇌ H⁺ + HCO₃⁻`
3. `HCO₃⁻ ⇌ H⁺ + CO₃²⁻`

## [cite_start]2. 溶解氧剖面分析 [cite: 7]
垂直方向上，溶解氧含量呈现以下特征：
* [cite_start]**表层**：受海气交换影响呈饱和态。 [cite: 5]
* **中层**：由于生物分解剧烈耗氧，形成“氧极小值层”。
* **深层**：受极地富氧冷水注入影响，氧含量回升。
