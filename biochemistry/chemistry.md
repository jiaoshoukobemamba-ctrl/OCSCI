# 🧪 海洋化学：化学平衡与过程

本模块解析海洋中的化学成分及其动态平衡机制。

## 1. 关键现象解析
* **“死亡之手” (Brinicle)**：海水结冰时排出极高浓度的极冷盐水，因密度大而迅速下沉，冻结沿途海水形成冰柱。
* **恒比定律**：开阔大洋中常量组分的比例基本恒定。但在**河口径流、极地融冰、海底热液口**等区域会出现偏离。
* **盐度差异**：大西洋盐度高于太平洋，主因是大西洋蒸发大于降水，且通过地峡向太平洋输送水汽。

## 2. 海洋碳泵机制
海洋通过四个泵调节全球碳循环：
1. **溶解泵**：CO2 物理溶解并随温盐环流下沉。
2. **生物泵**：浮游植物固碳并以“海洋雪”形式沉降。
3. **碳酸盐泵**：生物形成 CaCO3 壳体后沉降。
4. **微生物碳泵 (MCP)**：将有机碳转化为长期封存的“惰性溶解有机碳”。

## 3. 溶解氧 (DO) 剖面

* **表层**：高氧（海气交换、光合作用）。
* **中层**：氧极小值层（有机物分解耗氧）。
* **深层**：氧含量回升（极地富氧冷水注入）。
